Design the Homepage for SixLabs MVP Phase 1.

SixLabs product context:
SixLabs is an AI-native creative generation platform for performance marketers. The long-term vision is to become an AI performance marketing operator, but MVP Phase 1 is focused only on the creative generation workflow.

In MVP Phase 1, SixLabs helps marketers replace the slow agency-style creative request process. Instead of writing a long brief, waiting on creative teams, and manually reviewing scattered outputs, a marketer can log in, submit a simple creative brief, upload assets, generate ad creatives, review categorized outputs, approve the best creatives, and download a package.

The experience should feel like an AI creative workspace that helps performance marketers move from intent to approved ads quickly.

MVP Phase 1 end state:
A marketer can:
- Log in to SixLabs
- Access a brand workspace
- See that the brand is ready to generate creatives
- Check available credits
- Start a new creative request
- Submit a brief in under 2 minutes
- Upload product or brand assets
- Generate categorized creative options
- Review previous generations
- Approve creatives
- Download an approved creative package

Core MVP 1 promise:
“Give SixLabs a brief in under 2 minutes. Get categorized, approval-ready ads back.”

MVP Phase 1 flow:
Login → Onboarding / brand setup → Homepage → Create new creatives → Generation progress → Review generated creatives → Approve creatives → Download package → My Generations.

Important scope restriction:
Do NOT design anything related to MVP 2 or MVP 3.

Do not include:
- Fatigue detection
- Performance alerts
- Investment health
- Media monitoring
- Meta spend monitoring
- Campaign optimization
- Recommended actions based on performance
- Media management
- Automated action execution
- Guardrails
- Retiring ads
- Reallocating budget
- Pausing ads
- Action approval workflows
- Operator activity feed
- Risk detection
- ROAS/CAC monitoring dashboards

This homepage is only for MVP Phase 1: manual creative generation from a marketer-provided brief.

Now design the Homepage.

Homepage purpose:
The Homepage is the user’s starting point after login. It should help the user quickly understand:
- They are in the correct brand workspace
- Their brand setup is ready
- They have enough credits to generate creatives
- They can start a new creative brief
- They can return to recent generations that are ready for review, approved, downloaded, or need edits

The homepage should feel like a calm creative generation hub, not an analytics dashboard.

Primary user mindset:
The marketer is coming in to create new performance ad creatives or review work they already generated. They want speed, clarity, and confidence. They should not feel like they are configuring a complex enterprise system.

The page should answer:
“What can I create next?”
“What creative work needs my review?”
“Is my brand workspace ready?”
“How many credits do I have?”

Design style:
Use a soft, minimal SaaS UI inspired by a calm AI workspace.
The visual style should feel close to the Superscale-style reference:
- Light warm-gray background
- Large rounded central workspace
- Slim left sidebar
- Soft cards
- Subtle borders
- Soft shadows
- Muted grayscale typography
- Thin, simple icons
- Lots of whitespace
- Calm premium feel
- Slight conversational feeling
- Clear hierarchy
- Modern B2B SaaS polish

Avoid:
- Dark mode
- Heavy gradients
- Dense tables
- Analytics dashboard layouts
- Neon AI visuals
- Overly technical UI
- Enterprise clutter

Navigation:
Use a slim left sidebar with only MVP 1 navigation:
- Home
- Create
- My Generations
- Settings

Active section should be Home.

Do not include Alerts, Actions, Learnings, Campaigns, Investment Health, or Guardrails in the navigation.

Workspace context:
The active workspace is “Cirkul.”
The user is “Aakash.”
Show the workspace selector somewhere in the sidebar or top area.
Show available credits somewhere visible: “2,840 credits left.”

Homepage content direction:
Create a homepage that feels useful immediately. It should include a warm welcome, a clear creation CTA, recent generation activity, credit balance, and brand readiness.

Recommended content to include:

1. Welcome / hero area
Use a warm greeting and clear product promise.

Suggested copy:
“Welcome back, Aakash”
“Create approval-ready Meta ads from a simple brief.”
“Start with a short brief. SixLabs will generate categorized creative options for review.”

Primary CTA:
“Create new creatives”

Secondary CTA:
“View my generations”

This should be the main action area of the page.

2. Brand workspace readiness
The user should know that the Cirkul workspace is ready to use.

Suggested copy:
“Cirkul workspace ready”
“Brand voice, product context, and creative rules are set.”

Possible readiness items:
- Brand voice added
- Product assets available
- Logo uploaded
- Creative rules saved

CTA:
“Review brand kit”

This should feel reassuring, not like a checklist chore.

3. Credits summary
Show credits clearly, because MVP 1 has a credit system tied to generation cost.

Suggested copy:
“2,840 credits available”
“Estimated 120 credits for a 6-ad generation set”
“Credits are deducted after generation completes.”

CTA:
“View usage”

This should feel like lightweight usage visibility, not a billing-heavy section.

4. Recent generations
The user should be able to return to previous creative jobs.

Suggested title:
“Recent generations”

Show a few recent generation jobs with clear statuses and next actions.

Example rows or cards:
- “Orange cartridge static ads” — Ready for review — Today — CTA: Review
- “Starter kit ads” — Approved — Yesterday — CTA: Download
- “Summer flavor concepts” — Needs edits — 3 days ago — CTA: Continue

Possible statuses:
- Draft
- Generating
- Ready for review
- Approved
- Downloaded
- Needs edits

The recent generations area should feel like a work queue for creative output, not a project management tool.

5. Quick start / guided prompt
Include a lightweight entry point that reminds users how easy it is to create.

Suggested copy:
“Start from a brief”
“Describe what you need, add product images or brand assets, and SixLabs will generate creative concepts, copy, layouts, and QA-ready outputs.”

CTA:
“Start brief”

Optional example prompt:
“Create static Meta ads for Cirkul orange flavor cartridges. Focus on people who struggle to drink enough water.”

This can be a card, prompt-style input, or CTA module. Let the design decide the best layout.

Empty state:
If there are no recent generations, show a helpful empty state.

Suggested copy:
“No generations yet”
“Create your first brief and SixLabs will generate approval-ready ad concepts.”
CTA:
“Create your first ads”

Important UX principles:
- The homepage should make the user want to start a creative brief.
- The homepage should make recent generations easy to find.
- The homepage should show credits without making billing feel like the main focus.
- The homepage should show brand readiness without overwhelming the user.
- The homepage should feel calm, premium, and guided.
- The user should never feel like they are looking at a media dashboard.
- The user should not see performance metrics, risk alerts, or automation language.

Suggested copy style:
Use clear, direct product copy:
- “Create approval-ready ads”
- “Start with a simple brief”
- “Ready for review”
- “Approved package ready”
- “Credits available”
- “Cirkul workspace ready”
- “Most briefs take under 2 minutes”
- “Recent generations”
- “Continue draft”
- “Download package”

Avoid these terms completely:
- Investment health
- Risks detected
- Fatigue detected
- Meta spend monitored
- Recommended action
- Executing
- Guardrails
- Automation
- Retire ads
- Reallocate budget
- Campaign optimization
- Performance operator
- Alerts
- Actions

Desired feeling:
The user should feel:
“I know where to start, my brand is ready, I can see my recent creative work, and I can create new ads quickly.”

Design a polished homepage for this MVP Phase 1 experience.
